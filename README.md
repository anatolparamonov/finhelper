# FinHelper - Telegram бот для учета финансов

Telegram-бот для учета расходов и доходов с автоматической записью данных в Google Sheets.

## Возможности

- ✅ Ввод фактических расходов и доходов
- ✅ Ввод запланированных расходов и доходов
- ✅ Выбор категорий из Google Sheets
- ✅ Автоматическое форматирование сумм (10 000, 1 000 000)
- ✅ Цветовое выделение сумм (зеленый для дохода, красный для расхода)
- ✅ Получение ссылки на таблицу через команду /report
- ✅ Подтверждение перед записью данных

## Установка

1. Клонируйте репозиторий или скачайте файлы проекта

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте Google Sheets API:
   - Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
   - Создайте новый проект или выберите существующий
   - Включите Google Sheets API и Google Drive API
   - Создайте сервисный аккаунт
   - Скачайте JSON ключ и сохраните как `credentials.json` в корне проекта
   - Поделитесь вашей Google таблицей с email сервисного аккаунта (найдите email в credentials.json)

4. Создайте Google таблицу со следующей структурой:

   **Лист "Sheet1" (или другое имя, указанное в .env):**
   - Столбец A: Дата
   - Столбец B: Время
   - Столбец C: Факт (расход/доход/План)
   - Столбец D: Сумма
   - Столбец E: Категория
   - Столбец F: Описание
   - Столбец G: Пользователь

   **Лист "Категории":**
   - Столбец 1: Заголовок "Расходы"
   - Столбец 2: Заголовок "Доходы"
   - Под заголовками - списки категорий в соответствующих столбцах

5. Создайте файл `.env` в корне проекта:
```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
GOOGLE_SHEET_ID=your_google_sheet_id_here
GOOGLE_SHEET_NAME=Sheet1
GOOGLE_SHEET_URL=https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit
CREDENTIALS_PATH=credentials.json
ADMIN_USER_IDS=123456789,987654321
```

   **ADMIN_USER_IDS** - список ID пользователей Telegram, которые могут использовать команду `/restart` для перезапуска бота. ID разделяются запятыми. Чтобы узнать свой ID, напишите боту [@userinfobot](https://t.me/userinfobot).

   Для получения токена бота:
   - Найдите [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Скопируйте полученный токен в `.env`

   Для получения ID таблицы:
   - Откройте вашу Google таблицу
   - ID находится в URL: `https://docs.google.com/spreadsheets/d/SHEET_ID/edit`

## Запуск

### Локальный запуск

```bash
python main.py
```

или

```bash
python bot.py
```

### Запуск на сервере

Для автоматического перезапуска при использовании команды `/restart` настройте процесс-менеджер:

- **Systemd** - см. `DEPLOYMENT.md`
- **Supervisor** - см. `DEPLOYMENT.md`
- **Docker** - см. `DEPLOYMENT.md`
- **PM2** - см. `DEPLOYMENT.md`

Подробные инструкции по развертыванию на сервере находятся в файле `DEPLOYMENT.md`.

## Использование

1. Запустите бота командой `/start` или нажмите кнопку "СТАРТ"
2. Выберите тип операции: Расходы или Доходы
3. Введите сумму в целых рублях (например: `10000` или `10 000`)
4. Выберите категорию из предложенных
5. Введите описание (или нажмите Enter для пропуска)
6. Подтвердите или отмените запись

### Команды

- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/report` - Получить ссылку на таблицу
- `/plan` - Ввести запланированные расходы/доходы
- `/test` - Быстрый ввод данных одной строкой (`+/- сумма категория [описание]`)
- `/restart` - Перезапустить бота (только для администраторов)
- `/cancel` - Отменить текущую операцию

## Форматирование чисел

Суммы автоматически форматируются с пробелами для разделения тысяч:
- `10000` → `10 000`
- `1000000` → `1 000 000`

## Цветовое выделение

- 🟢 Зеленый цвет - доходы
- 🔴 Красный цвет - расходы
- ⚪ Без цвета - запланированные записи
