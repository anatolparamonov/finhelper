# Система напоминаний FinHelper

## 📅 Обзор

FinHelper автоматически отправляет ежедневные напоминания для ведения учета финансов:
- **🌅 Утренние напоминания** - мотивируют начать день с записи расходов
- **🌙 Вечерние напоминания** - напоминают подвести итоги дня

## ⏰ Настройка времени

### Через команду `/reminders`

1. Введите `/reminders` в боте
2. Нажмите **"⏰ Время утреннего"** или **"🌙 Время вечернего"**
3. Введите время в формате `ЧЧ:ММ` (например: `07:30`, `23:15`)
4. Бот автоматически перезапустит напоминания

### Через файл настроек

Настройки сохраняются в файле `reminder_settings.json`:

```json
{
  "morning_time": "08:00",
  "evening_time": "22:20"
}
```

### Через переменные окружения

В файле `.env`:

```env
MORNING_REMINDER_TIME=08:00
EVENING_REMINDER_TIME=22:20
```

**Приоритет настроек:** `.env` → `reminder_settings.json` → значения по умолчанию

## 🔧 Управление

### Команды:
- `/reminders` - открыть меню управления напоминаниями
- `/help` - справка с информацией о напоминаниях

### Кнопки в меню `/reminders`:
- **⏰ Время утреннего** - изменить время утреннего напоминания
- **🌙 Время вечернего** - изменить время вечернего напоминания
- **🔄 Перезапустить напоминания** - применить настройки заново
- **🧪 Тест утреннего** - отправить тестовое утреннее напоминание
- **🧪 Тест вечернего** - отправить тестовое вечернее напоминание

## 👥 Получатели напоминаний

Напоминания отправляются всем пользователям, указанным в `ADMIN_USER_IDS` в файле `.env`:

```env
ADMIN_USER_IDS=123456789,987654321
```

## 🛡️ Безопасность

- Только администраторы (из `ADMIN_USER_IDS`) могут управлять напоминаниями
- Настройки сохраняются локально в файле `reminder_settings.json`
- Валидация времени (ЧЧ:ММ, 00:00-23:59)

## 🔄 Автоматический перезапуск

При изменении времени напоминаний:
1. Старые задачи автоматически удаляются
2. Создаются новые задачи с обновленным временем
3. Настройки сохраняются в файл для следующих запусков
4. Пользователь получает подтверждение об изменениях

## 📱 Интерактивность

Каждое напоминание содержит кнопку **"СТАРТ"** для быстрого перехода к вводу данных.

## 🚀 Развертывание

При развертывании на сервере напоминания работают автоматически:
- Используют системное время сервера
- Сохраняют настройки между перезапусками
- Логируют все действия для диагностики

## 📝 Логирование

Все действия с напоминаниями логируются:
- Настройка времени
- Отправка напоминаний
- Ошибки планировщика
- Изменения настроек

Пример логов:
```
2025-11-26 22:35:23 - bot - INFO - Настроено утреннее напоминание на 08:00
2025-11-26 22:35:23 - bot - INFO - Настроено вечернее напоминание на 22:20
```
